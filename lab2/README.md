# Лабораторна робота – Частина 1

Створено Python-venv з потрібними бібліотеками.

Завантажено дані VHI для 24 областей України у папку data, уникаючи повторного завантаження.

Очищено дані: видалено зайві рядки/стовпці, приведено числа до float, додано назви та індекси областей.

Змінено індекси областей на українську абетку (1 – Вінницька … 24 – Чернігівська).

Реалізовано функції для отримання VHI за рік, за діапазон років та для статистики (min, max, mean, median).
