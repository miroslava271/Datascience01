# Лабораторна робота №5  
## Наука про дані: обмін результатами та початковий аналіз

##  Мета роботи
Розробити інтерактивний веб-додаток для аналізу часових рядів індексів VHI/VCI/TCI з використанням бібліотеки Streamlit.

## Завдання роботи
У рамках лабораторної роботи необхідно:

- створити веб-додаток за допомогою Streamlit;
- реалізувати dropdown список для вибору індексу (VHI, VCI, TCI);
- реалізувати dropdown список для вибору області;
- додати slider для вибору інтервалу років;
- додати slider для вибору інтервалу тижнів;
- реалізувати кнопку для скидання фільтрів;
- створити таблицю з відфільтрованими даними;
- побудувати графік часових рядів;
- реалізувати графік порівняння областей.
