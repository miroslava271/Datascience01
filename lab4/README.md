# Лабораторна робота №4
## Опис роботи

У цій лабораторній роботі реалізовано інтерактивну програму для побудови гармонічного сигналу виду:

y(t) = A * sin(ωt + φ)

з можливістю додавання шуму та його фільтрації.

Користувач може змінювати параметри сигналу та шуму за допомогою інтерактивних елементів.

## Функціонал

- Побудова чистої гармоніки
- Додавання випадкового шуму
- Інтерактивні слайдери:
  - амплітуда
  - частота
  - фаза
  - параметри шуму
- Чекбокс для увімкнення/вимкнення шуму
- Кнопка Reset
- Фільтрація сигналу (Butterworth filter)
- Відображення:
  - чистого сигналу
  - зашумленого сигналу
  - відфільтрованого сигналу
