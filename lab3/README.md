# Лабораторна робота №3 — Візуалізація даних

У цій роботі було обрано датасет з ресурсу UCI Machine Learning Repository, який містить як числові (integer/real), так і категоріальні атрибути та має пропущені значення.

Було виконано попередню обробку даних (Data Cleaning): перевірено та оброблено пропущені значення, перевірено типи даних та підготовлено дані до аналізу.

На основі датасету побудовано кілька типів графіків для дослідження залежностей між атрибутами та аналізу розподілу даних. Зокрема побудовано:

* графіки залежності між числовими атрибутами (scatter plot, line plot);
* гістограму розподілу значень одного з атрибутів у 5 діапазонах;
* додаткові графіки (boxplot, heatmap, bar plot) для візуального аналізу даних.

Загалом у роботі побудовано 5–8 графіків, що дозволяють краще зрозуміти структуру даних та виявити залежності між змінними.

Результати оформлено у вигляді Jupyter Notebook та розміщено у репозиторії GitHub.
